# TeleWave — настоящий веб-мессенджер

Это исходный проект для общения между разными пользователями через интернет. В отличие от демо, сообщения хранятся в Supabase и доставляются в реальном времени.

## Что работает
- Регистрация и вход по email/паролю.
- Автоматический профиль с ником.
- Поиск пользователей по нику.
- Личные чаты.
- Создание групп и добавление участников.
- Текстовые сообщения в реальном времени.
- Отправка изображений, видео и голосовых записей (до 30 МБ).

## Важно
Это стартовая версия, не готовый публичный сервис. Для работы нужен собственный проект Supabase и размещение сайта. Не публикуй секретные ключи. Используй только `anon`/publishable key во фронтенде, никогда не вставляй `service_role`.

## 1. Создай сервер Supabase
1. Открой https://supabase.com и создай бесплатный проект.
2. В проекте открой **SQL Editor → New query**.
3. Скопируй весь файл `supabase/schema.sql`, вставь и нажми **Run**.
4. Открой **Project Settings → API** (или Connect) и скопируй Project URL и anon/public key.

## 2. Запусти сайт
Нужен компьютер с Node.js 20 или новее.
1. Распакуй архив.
2. В папке проекта создай файл `.env` на основе `.env.example`.
3. Вставь значения:
   ```
   VITE_SUPABASE_URL=https://твой-проект.supabase.co
   VITE_SUPABASE_ANON_KEY=твой-публичный-anon-ключ
   ```
4. В терминале в папке проекта выполни:
   ```
   npm install
   npm run dev
   ```
5. Открой адрес, который покажет Vite (обычно http://localhost:5173).

## 3. Дай друзьям доступ
Чтобы друзья общались с тобой не только в одной Wi-Fi сети, сайт нужно опубликовать (например, на Vercel или Netlify):
1. Загрузи папку проекта в свой GitHub.
2. Импортируй репозиторий в Vercel.
3. В настройках Environment Variables добавь те же `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. Нажми Deploy и отправь друзьям публичную ссылку.
5. В Supabase → Authentication → URL Configuration добавь адрес сайта в Site URL и Redirect URLs.

## Как начать общаться
1. Каждый регистрируется со своим email и паролем.
2. В поиске нажми значок лупы и введи ник друга (ник показывается вверху у каждого пользователя).
3. Открой личный чат или создай группу и выбери участников.

## Ограничения этой версии
- Подтверждение email может быть включено в настройках Supabase Auth. Если включено, сначала подтвердите почту.
- Публичные ссылки на вложения доступны тем, у кого есть URL. Для приватного продакшена нужно заменить bucket на private и выдавать signed URLs.
- Нет push-уведомлений, восстановления пароля и полноценной модерации.
- Перед публичным запуском стоит усилить правила приглашения в группы, добавить лимиты, жалобы/блокировки и защиту от спама.
